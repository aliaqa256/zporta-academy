# Zporta Academy - Frontend Application (Next.js)

## Quick Start

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Build & Production
```bash
npm run build
npm run start
```

### Key Architectural Conventions
- **Styling**: Vanilla CSS / CSS Modules using tokens in `src/styles/`.
- **Theme Support**: Seamless Light/Dark mode with `data-theme` attribute and `localStorage` persistence.
- **Modals**: Use `useScrollLock` to avoid background document scrolling during overlays.

For full system details and conventions, see [AGENTS.md](file:///../../AGENTS.md).
